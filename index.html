The Five-Stage Product Model

1. Observe

Collect raw local network signals, DNS metadata, and host endpoint context safely when exposed by the operating system.

2. Normalize

Convert disparate measurements into typed, bounded evidence objects with full provenance and coverage ceilings.

3. Interpret

Run local feature analysis, personal behavioral baselines, and anomaly detectors without relying on cloud-based heuristics.

4. Control

Compile and apply explicit, reversible, deterministic protection rules across DNS, URL, and browser-policy surfaces.

5. Explain

Expose confidence ratings, data limitations, and failure states transparently through a native SwiftUI operator cockpit.
